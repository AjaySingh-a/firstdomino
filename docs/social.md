## Dev's LinkedIn post

Every prescription looked reasonable. The chain didn't.
A blood pressure pill can bring on ankle swelling, and the swelling gets treated with a water pill: a prescribing cascade no single visit shows.
For Graph Hacks, Ajay and I built FirstDomino. It finds that chain in a synthetic patient's record as one walk through a graph, and asks for the one missing fact a clinician needs. The clinician still decides.
I built the engine on @FalkorDB: Cypher that matches through drug classes, a path the database returns itself, and algo.SPpaths to prove when a lookalike medicine has no link at all.

## Ajay's LinkedIn post

What does an AI agent look like when it isn't allowed to decide anything?
For Graph Hacks, Dev and I built FirstDomino. It flags possible prescribing cascades in synthetic patient records, so a pharmacist can review them and a clinician can decide.
I built the web app, the review agent and the MCP server. The agent has six allowlisted tools and at most six steps. Every reply is checked, it falls back to templates, and every step is saved in @FalkorDB, so a second run answers "from memory" instead of asking the caregiver again.
The same tools work in Claude Desktop through our MCP server, and they never write a single line of Cypher.
